NEON TIDE: Port Solano is an original open-world crime game in three.js, built for make.fun's "Make GTA 6" bounty. You play Mara Quill, a getaway driver back in the sunset harbour city of Port Solano: 8x8 blocks to roam on foot or in any car you can steal, live traffic and pedestrians, a five-star wanted system with police who chase and box you in, fists and a pistol, two story missions for the Tidewater crew, a HUD with a live minimap, and a title screen with save and continue. No build step and no network requests: three.js is vendored, and every texture and sound is generated in code. To hand the entry in, run `node main.ts`: it copies game/ and screenshots/ to the output directory and writes the dossier the judge reads.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser.
